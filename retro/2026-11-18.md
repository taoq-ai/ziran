Add under "Gates and builders" in `.wuwei/standards.md`:

> taoq-ai/ziran archive copies (2026-11-18, note until 2026-11-23): `git archive` drops `.git`, so
> set `SETUPTOOLS_SCM_PRETEND_VERSION=0.0.0` for `uv sync` and `uv build`. When you use the main
> checkout's venv, pin `PYTHONPATH=<copy>` and confirm `ziran.__file__` is inside the copy. Lint
> named folders (`ruff check ziran tests benchmarks scripts`), never `.`, which lints the copy's
> `.venv`. Tests that call git (`test_external_eval_*`,

this is a repository fact seats keep re-learning. Add the same line to ziran's `CLAUDE.md` through
